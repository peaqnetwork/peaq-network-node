# Project

This is an experimental project about new Substrate-pallet that manages DIDs on a Substrate-based blockchain.
The pallet is designed to be flexible and extensible, allowing for various DID methods and verification relationships.
The pallet provides a set of extrinsics for creating, updating, and deleting DIDs, as well as managing verification methods and services associated with DIDs.
For now, we don't need to fully implement the pallet, but we want to design some basic data structures and benchmark a validation function for the DIDs.
